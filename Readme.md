# EduBatch

Education Batch Management Platform.

## Stack

- React + Vite
- Tailwind CSS
- Node.js + Express
- MongoDB + Mongoose
- JWT + bcrypt
- Razorpay

## Project Structure

- `client/` — React frontend
- `server/` — Express backend
- `docs/` — project documentation

## Development

### Frontend

cd client
